# Bridge Coding Harness

هارنس کدنویسی ویندوز با فضای فایل اختصاصی هر گفتگو و نمایش خروجی داخل اپ — **بدون نیاز به Docker یا نصب جداگانهٔ Python و Node**.

[دانلود نصب‌کنندهٔ Windows x64](https://github.com/Alikavoosi21/bridge-coding-harness/releases/latest) · [راهنمای شروع](docs/QUICKSTART.fa.md) · [جزئیات نسخهٔ 0.3.0](docs/LOCAL-WORKSPACE-0.3.0.fa.md)

![نشان Bridge](public/brand/approved-bridge.svg)

## شروع کار

۱. فایل نصب را از Releases دریافت و نصب کن.
۲. مدل و API key شخصی خودت را در تنظیمات اپ وارد کن و توانایی ابزار را بررسی کن.
۳. درخواست بده؛ مثلاً «یک صفحهٔ ورود بساز». برنامه را تأیید کن؛ ایجنت فایل‌ها را در فضای همان گفتگو می‌نویسد و اصلاح می‌کند. انتخاب پوشه اجباری نیست.
۴. **اجرا و نمایش** را بزن؛ خروجی داخل اپ باز می‌شود. کپی‌کردن کد به ابزار دیگر یا واردکردن فرمان برای مسیر معمول لازم نیست. تنظیمات فرمان و پورت در بخش پیشرفته‌اند.

نسخهٔ نصب‌شده Python و Node/npm را همراه دارد. فایل‌ها و تاریخچه در داده‌های Bridge ذخیره می‌شوند. Apply فقط برای انتقال تغییرها به پروژهٔ انتخابی است؛ دیدن خروجی به Apply نیاز ندارد. پروژهٔ دارای وابستگی برای دریافت پکیج‌ها به اینترنت نیاز دارد.

## قابلیت‌ها

- برنامه‌ریزی قابل ویرایش و تأیید پیش از اجرا؛ گفتگو، سؤال و اصلاح درخواست در همان چت.
- خواندن و جستجوی پروژه، نوشتن فایل، اجرای کد، نصب پکیج و تست با ابزارهای همراه.
- بررسی خروجی و اصلاح خودکار؛ پس از دو تلاش ناموفق، تصمیم انسانی برای تمدید یا توقف.
- ساخت یا ورود Skill از فایل، پوشه و ZIP؛ فراخوانی با `/`.
- تأیید/ویرایش/رد عملیات حساس، مجوز همین تسک، توقف واقعی درخت پردازش، تاریخچه و بازیابی.
- diff و ویرایش دستی، اعمال انتخابی و بازگردانی با حفظ تغییرهای کاربر.
- HTML/CSS/JavaScript تعاملی داخل اپ، پنجرهٔ جدا و لینک مرورگر؛ اجرای Python و وب‌سرور Node.
- رابط فارسی RTL و طراحی سبز Bridge، دریافت مدل‌های سرویس و ذخیرهٔ امن کلید در خود اپ.

## اجرای محلی و حریم خصوصی

**این نسخه sandbox سیستم‌عامل نیست:** فرمان‌های محلی دسترسی حساب ویندوز و شبکهٔ کاربر را دارند. فایل‌های گفتگو جدا هستند، اما این جدایی جلوی دسترسی کد مخرب به همهٔ فایل‌های کاربر را نمی‌گیرد. کلید API و توکن موتور به محیط فرمان تحویل داده نمی‌شوند. عملیات حساس و Apply همچنان تأیید می‌خواهند. Windows Job Objects پردازش‌های متعلق به اجرا را هنگام Stop یا خروج موتور می‌بندند.

کلید مدل در Windows Credential Manager است؛ داخل سورس، `.env.example` و نصب‌کننده کلید مشترکی وجود ندارد. داده‌ها در `%APPDATA%/BridgeCodingHarness` هستند. گفتگو و فایل‌های خوانده‌شده به سرویس مدل انتخابی شما ارسال می‌شوند. `.env` واقعی، تاریخچه، دیتابیس، trace و پروژه‌های شخصی منتشر نمی‌شوند. جزئیات: [SECURITY.md](SECURITY.md).

گفتگوهای قدیمی حفظ می‌شوند. اولین انتقال یک گفتگوی Docker به اجرای محلی، تأیید برنامه و مجوز قبلی را باطل می‌کند تا اختیار قبلی بی‌صدا تعمیم داده نشود. بررسی‌های محیط قبلی، تأیید محیط جدید نیستند.

## توسعه از سورس

پیش‌نیاز توسعه در ویندوز: Node.js 24 و Python 3.11 یا 3.12. کاربر نسخهٔ نصبی به نصب جداگانهٔ این ابزارها نیاز ندارد.

```powershell
npm ci
py -3.11 -m venv backend/.venv
backend/.venv/Scripts/python.exe -m pip install -e "./backend[dev]"
node scripts/build-toolchain.cjs
npm run desktop
```

```powershell
npm run test:harness
npm run test:engine
npm run typecheck
npm run build:desktop-ui
npm run desktop:build
```

خروجی بسته‌بندی در `release/dist/` است. `.env.example` فقط تنظیمات اختیاری توسعه را توضیح می‌دهد؛ `.env` خودکار بارگذاری نمی‌شود. تست‌های تاریخی مخصوص Docker بدون پیش‌نیاز واقعی skipped می‌شوند؛ مسیر پیش‌فرض جدید از LocalRuntime استفاده می‌کند.

## معماری و بررسی

Next.js، shadcn و Vercel AI SDK برای رابط؛ Electron برای دسکتاپ؛ FastAPI، Deep Agents و LangGraph برای موتور؛ SQLite و checkpoint برای ماندگاری. اجرای محلی با Python و Node/npm همراه و مدیریت پردازش ویندوز انجام می‌شود.

شواهد 0.3.0: مجموعهٔ کامل بک‌اند ۴۴۱ موفق و ۳ skipped؛ تست‌های هدفمندِ تکمیلی موفق؛ ۲۲ بررسی اجرای خروجی و ۱۹ بررسی ساخت فایل تا نمایش در نسخهٔ بسته‌بندی‌شده موفق؛ ۲۲ بررسی اجرا روی نسخهٔ نصب‌شده موفق. مدل واقعی در ۱۳ بررسی، شکست تست، اصلاح منبع و موفقیت همان تست را بدون Docker تأیید کرد. این اعداد تضمین حل هر پروژه یا پشتیبانی از تمام فریم‌ورک‌ها نیستند.

نصب‌کننده امضای ناشر ندارد و ممکن است SmartScreen هشدار بدهد. SHA-256 کنار فایل نصب منتشر می‌شود. پیش‌نمایش پس از restart خودکار از سر گرفته نمی‌شود.
