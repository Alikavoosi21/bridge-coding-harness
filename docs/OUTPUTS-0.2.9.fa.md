# اجرای خروجی و پیش‌نمایش — Bridge 0.2.9

در بالای گفتگوی هر کار، «پیش‌نمایش index.html» یا «اجرا و پیش‌نمایش» را بزنید. این دسترسی در مرور تغییرها و نتیجهٔ اعمال نیز وجود دارد.

- **HTML:** فایل را انتخاب کنید؛ CSS، JavaScript و فایل‌های نسبی آن در پیش‌نمایش باز می‌شوند. «پنجرهٔ جدا» و لینک «بازکردن در مرورگر» هم در همان بخش هستند. لینک واقعی پس از آماده‌شدن خروجی نمایش داده می‌شود.
- **اجرای کد:** فرمانی مثل `python main.py` را وارد کنید و «تأیید فرمان و اجرا» را بزنید. خروجی واقعی ترمینال و کد خروج نمایش داده می‌شود؛ سقف این اجرای کوتاه ۱۲۰ ثانیه است.
- **اجرای وب:** فرمان پروژه را انتخاب یا وارد کنید، نوع اجرا را «برنامهٔ وب و لینک بازکردن» بگذارید و پورت را تعیین کنید. سرور باید روی `0.0.0.0` و همان پورت گوش کند. پیشنهادهای پروژه برای Next و Vite این تنظیم را اضافه می‌کنند؛ برای فرمان دستی آن را بررسی کنید. دکمهٔ تأیید فرمان و شبکه، دسترسی شبکهٔ این اجرای جدا را هم مجاز می‌کند. لینک فقط روی همین دستگاه در دسترس است و پس از پاسخ واقعی HTTP ظاهر می‌شود.
- **نصب وابستگی:** در صورت نیاز، فرمان نصب را بررسی و رضایت جداگانهٔ نصب با شبکه را فعال کنید. این نصب داخل کپی اجرا انجام می‌شود؛ پکیج روی ویندوز شما نصب نمی‌شود.
- **توقف:** «توقف خروجی» سرور را می‌بندد و لینک را از دسترس خارج می‌کند. پیش‌نمایش حداکثر ۲۰ دقیقه فعال است؛ پس از بستن و بازکردن برنامه، اجرا خودکار از سر گرفته نمی‌شود.

اجرای فرمان و وب به Docker فعال و تصویر محیط Bridge نیاز دارد. HTML ساده بدون اجرای فرمان نیز قابل مشاهده است. اجرا روی کپی جدا از نسخهٔ کاری انجام می‌شود؛ فایل اصلی پروژه و تغییرهای در حال بررسی دست‌نخورده می‌مانند. برای ساخت و ویرایش فایل با ایجنت، حالت فقط‌خواندن را غیرفعال کنید.

پیش‌نمایش داخلی به API دسکتاپ و Node دسترسی ندارد. HTML محلی و فایل‌های نسبی پشتیبانی می‌شوند؛ اتصال به CDN و سرویس‌های بیرونی در پیش‌نمایش داخلی محدود است. پنجرهٔ مرورگر خارجی رفتار عادی همان مرورگر را دارد.

## شواهد این نسخه

- بک‌اند: ۴۳۸ موفق و ۳ skipped؛ قراردادهای رابط: ۴۸ موفق؛ typecheck و build موفق.
- آزمون عملی: HTML با CSS و JavaScript نسبی، تعامل دکمه، پنجرهٔ جدا، اجرای واقعی Python، وب‌سرور واقعی Node، لینک محلی، توقف، حفاظت از فایل اصلی، عرض ۱۴۴۰ و ۱۰۲۴.
- مدل demo فقط برای آماده‌کردن fixture آزمون استفاده شد؛ اجراهای Python و Node واقعی و داخل Docker بودند. تولید کد با مدل پولی دوباره آزمایش نشد.
- نسخهٔ بسته‌بندی‌شدهٔ 0.2.9 نیز هر ۲۰ بررسی خروجی و ۹ بررسی عملکرد را گذراند؛ تشخیص Docker خارج از PATH نیز با مسیر ثبت‌شدهٔ نصب ویندوز کار کرد. نسخهٔ نصب‌شدهٔ 0.2.8 حذف شد و AppData حفظ شد؛ نصب خودکار نسخهٔ جدید انجام نشد.
- همهٔ فریم‌ورک‌ها آزمایش نشده‌اند. پس از بسته‌شدن اجباری موتور، بازیابی خودکار نشست پیش‌نمایش نداریم؛ اجرای وب سقف ۲۰ دقیقه دارد.
