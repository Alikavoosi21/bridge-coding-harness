# استفاده از هویت Bridge

نشان منتخب کاربر، حرف H با دو ستون ثابت و یک اتصال پله‌ای است. از فایل SVG اصلی استفاده کنید و هندسه را دوباره رسم نکنید.

رنگ اصلی `#4ADE80` روی زمینهٔ `#010A04` است. برای سطوح روشن از `bridge-horizontal-ink.svg`، برای سطوح تیره از `bridge-horizontal.svg` و برای چاپ تک‌رنگ از نشان مشکی یا سفید استفاده کنید. نسخهٔ سبز روی سفید برای متن کوچک انتخاب مناسبی نیست.

حداقل اندازهٔ نشان اصلی ۲۴ پیکسل است؛ برای ۱۶ پیکسل فقط `bridge-small.svg` استفاده شود. اطراف نشان حداقل به اندازهٔ ضخامت ستون آن فضای خالی بگذارید؛ در فایل ۲۵۶ واحدی، ۴۰ واحد. امضای افقی را در اندازه‌ای نمایش دهید که نام به‌راحتی خوانده شود؛ در نوارهای باریک فقط نشان را همراه نام متنی دسترس‌پذیر به کار ببرید.

نشان را نکشید، نچرخانید، به آن سایه و بافت اضافه نکنید و فاصلهٔ حروف امضای آماده را تغییر ندهید. طبق بازخورد کاربر، در انیمیشن‌های وضعیت چرخش سه‌بعدی، تغییر زاویه، باز شدن اتصال و تبدیل فرم مجاز است؛ نشان ثابت و فایل‌های اصلی هویت تغییر نمی‌کنند. رنگ کهربایی انتظار و اصلاح بخشی از وضعیت رابط است، نه رنگ جایگزین هویت.

نام قابل خواندن برای فناوری کمکی «Onboard Harness» است. آیکون تزئینی کنار همین نام نباید دوباره خوانده شود. GIF باید متن وضعیت و پوستر ثابت برای کاهش حرکت داشته باشد. بررسی ثبت علامت تجاری در این تحویل انجام نشده است.
