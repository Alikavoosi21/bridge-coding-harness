# نمونهٔ امن برای اولین تسک

این پوشه یک باگ عمدی دارد و شامل داده یا کلید شخصی نیست.
آن را به‌عنوان پروژه در Bridge انتخاب کنید و این درخواست را بفرستید:

«تابع add در main.py اشتباه است. اول python check.py را اجرا کن، فقط main.py را
اصلاح کن و دوباره تست بگیر. check.py را تغییر نده. پیش از اعمال، diff را نشان بده.»

فرمان تست: `python check.py`؛ بدون dependency یا نصب پکیج.
شکست تست اولیه عمدی است و بعد از اصلاح باید پاس شود.
